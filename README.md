# My Expense Tracker v2
A low-cost, single-user iPhone PWA.

Features: camera/photo OCR, local PDF text extraction, Gmail receipt attachment import, Google Drive Picker import, local IndexedDB storage, reports, CSV export, JSON backup/restore.

No Apple Developer membership is required. Host the static files on GitHub Pages and add the site to the iPhone Home Screen.

Google integration is optional. Follow GOOGLE_SETUP.md once you have the app on GitHub Pages.

Important: data is local to the browser. Export JSON backups regularly. Clearing Safari website data can erase local records.
